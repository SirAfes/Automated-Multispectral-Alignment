# Example data

Example imagery is intentionally not bundled with the source repository because raw multispectral images can be large and may have dataset-specific usage restrictions.

A useful public example should contain:

- one original compound multispectral image;
- the six split lens images;
- the final aligned 14-band TIFF;
- the corresponding alignment-quality report; and
- one small visual comparison showing registration before and after processing.

When publishing example data, verify that you have permission to redistribute the source imagery.
